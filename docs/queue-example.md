# queue.md 示例

这个文件本身就是一份合法的 `queue.md`：第一个 `##` 之前的内容（包括这段说明）工具不读。
复制到 `.drover.conf` 里 `HANDOFF_DIR` 指的那个目录下当 `queue.md`，删掉不要的块就能用。

**格式只有一条硬规定**：顶格的 `## 标题` 或 `## T7 标题` 开始一个任务，到下一个顶格 `## ` 之前的
所有内容都是它的正文，`review-task next` 原样发给主控。编号可省，发出时自动补；文件里的先后就是
执行顺序。正文里的小标题用 `###`，别用 `##`。

正文就是人当面交代的那些话，怎么做、交给谁、审不审都由主控按 AGENTS.md 决定 —— 那是内循环的事，
队列不管。想让某个任务跳过规划，正文里写一句「不走规划」就行，它只是一句普通的话。

两行特殊写法（各自单独占一行，冒号中英文都行）：

- `做完：等我放行` —— 这个任务做完后停下等放行，外层循环开着时也停，放行后接着转。人一般直接点看板上的「做完停」，这一行主要给 agent 建任务用。
- `验收：<命令>` —— 这件活算完的标准，覆盖 `.drover.conf` 里的 `CHECK_CMD`（完成判据第 3 条）。它会被当成 shell 命令在仓库根跑，退出码 0 才算过。**只能在这个文件里写**，看板的加/改任务表单不收它——一个输入框变成任意命令执行不划算。

**正文建议写三件事**：目标或现象、范围（尤其是不做什么）、怎么算做完。写得越具体，来回越少。
