### 3. 比较

| | A 色彩预算 | B 状态带 + 自适应 | C 三列看板 |
|---|---|---|---|
| 可读性 | 状态一眼可辨；结构不变，空间问题（O2）不解决 | 解决 O1–O4；80×24 首屏能看到判据 + agent + 队列摘要 | 宽屏全局感最强；进行中卡片变窄，正文 / 判据折行更碎 |
| 信息完整性 | 不删不改文字；D1 只换颜色 | 摘要是**额外**一行，完整内容仍在下方；判据单行只是不换行 | 不删信息，但各列独立溢出，要么共用翻页，要么各自滚动 |
| 实施范围 | `init_colors()` + `task_heading` 绘制 + 几处 kind；约几十行 | `draw()` 布局、`detail_sections(presentation)`、`wrap_lines()`；中等 | `draw()` 布局、T8/T13 的命中矩形、视口规则重写；大 |
