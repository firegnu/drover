- 影响：agent、待办、历史连续堆在辅栏；agent 的即时状态、下一件待办和已完成历史虽然有标题，但都用相近的行级表达。待办标题或历史指标一换行，辅栏可能比主栏明显更“满”，造成当前任务/判据的注意力被右栏吸走。历史放弃原因仍必须可见，不能靠删历史或隐藏原因解决。
