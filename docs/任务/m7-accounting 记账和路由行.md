## 要做的

### 1. 记账三项（待定 3 的结论）

「做完的」栏每件活显示：**耗时**、**提交数**、**等放行时长**。全部从现有数据算，不加新事件、不改事件格式：

- **耗时** = `done` 事件的 `t` − `start` 事件的 `t`（`task_fold` 折出来的 `t1 - t0`）。
- **提交数** = `task_commits(start_sha, end_sha)` 的长度。现成函数，别另写。
- **等放行时长** = `go` 事件的 `t` − `done` 事件的 `t`。**只有放行模式（`done` 事件带 `gate`）才有这一项**；自动模式没有 `go` 事件，这一项不显示，不要显示成 0。

`task_fold` 现在不记 `go` 的时间，要让它记下来。注意它的返回结构被别处依赖，**加字段可以，别改已有字段的含义**。

> **「返工轮数」不要做。** ROADMAP 已经写明它记不出来：drover 看不见主控和 dev agent 之间的往返（硬规矩第 4 条）。提交数照记，但它就叫「提交数」，**不许在任何文案里把它叫成或暗示成返工轮数**。

时长怎么显示：沿用仓库里现成的 `ago()` 那套口径，别自己发明格式。
